# Judge Memory v1

Purpose:
Long-term decision memory for Judge AI.

Rules:

* Store only final conclusions.
* Record why ideas survived or failed.
* Penalize repeated weak hypotheses.
* Reward ideas surviving strong criticism.

Evaluation Heuristics:

High Confidence:

* strong evidence
* low assumption load
* survives criticism

Low Confidence:

* speculative
* weak evidence
* large logical leaps

Common Failure Patterns:

* hidden energy assumptions
* correlation mistaken as causation
* analogy treated as proof
* mystery used as evidence
